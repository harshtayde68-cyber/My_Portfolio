# Harsh Tayde — Portfolio

A personal portfolio website for Harsh Tayde, a first-year B.Tech Computer Science (AI/ML) student at Bosscoder School of Technology. The site introduces Harsh, highlights his skills and project work, and provides a way to get in touch.

## Sections

- Home and introduction
- About me
- Skills
- Projects, including LogMind AI
- Contact information

## Built with

- Semantic HTML
- CSS

## Run locally

1. Clone or download this repository.
2. Open `index.html` in a web browser.

## Publish with GitHub Pages

Push the site files to a GitHub repository, then enable GitHub Pages for that repository in its settings. The site entry file should be named `index.html`.
